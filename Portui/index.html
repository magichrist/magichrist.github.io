Portui

Ports Explorer — lsof and psutil, but make them pretty.

Python 3.12+ Built with Textual macOS only MIT license 281 tests passing

Portui (Ports Explorer) is an interactive terminal explorer for macOS processes, network sockets, and open file descriptors. It shows you what's listening, who owns it, and what it has open — with six candy-coloured themes, keyboard-first navigation, and honest reporting when macOS hides something.

GitHub

Key Features

  • Process browser — every visible process with PID, PPID, user, CPU, memory, runtime, status, and full path; searchable by any field
  • Six focus views — Overview, network connections, TCP listeners, files, UNIX sockets, and all open descriptors
  • Field-scoped search — port=8080, state=LISTEN, proto=UDP, rport=443, lip=127.0.0.1, fd=10, or plain words
  • Responsive tables — sheds low-priority columns as your terminal narrows
  • Six themes — Gummy, Midnight, Tokyo Night, Gruvbox, Nebula, Daylight; switch live with Ctrl+T
  • Honest output — permissions stated, never faked; unavailable values render as —, not 0
  • Read-only, mostly — nothing closes a connection or deletes a file; process termination takes two deliberate keystrokes

Quick Install

brew install lsof
git clone https://github.com/magichrist/Portui
cd Portui
python3 -m pip install -e .
ports-explorer

Requires Python 3.12+ and macOS lsof.

Who Is This For?

macOS developers and security researchers who want a clear, honest, keyboard-driven view of what's running on their machine — which processes own which sockets, which files are open, and what's listening on the network.
