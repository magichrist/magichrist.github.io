Kali MCP

A warm, expressive MCP server that puts 56 Kali Linux pentesting tools at your AI agent's fingertips.

Kali MCP is a production-grade Model Context Protocol (MCP) server that exposes Kali Linux penetration-testing tools — nmap, sqlmap, nuclei, hydra, metasploit, ffuf, katana, subfinder, amass, bettercap, responder, zap, wpscan, and 44 more — to AI agents. Every tool call is validated against a JSON schema, every execution is sandboxed with timeouts, and every result is stored in a shared inter-agent vault.

GitHub PyPI — pip install kmcp

Key Features

  • 56 native Kali tool wrappers — nmap, sqlmap, nuclei, hydra, metasploit, ffuf, katana, subfinder, amass, bettercap, responder, zap, wpscan, and more
  • generic_command — escape hatch to run any shell command or pipeline not covered by a native wrapper
  • python_command — execute Python scripts directly on the host
  • Playbooks — multi-step pipelines (recon, webapp, AD, custom) with {{target}} substitution and resume support
  • parallel_execute — fan out to multiple tools concurrently, then aggregate and deduplicate results
  • Inter-agent vault — SQLite-backed knowledge store; any agent can write findings, credentials, or notes and query them back
  • Live monitor TUI — kmcp monitor shows connected users, running jobs, and server health with SSE push
  • Safety — 3-layer timeout defense, process-tree cleanup, semaphore limits, output truncation

Quick Install

pip install kmcp
kmcp start

The server listens on http://0.0.0.0:8399/mcp by default (HTTP/SSE or streamable-http). Point your MCP client at that URL.

Who Is This For?

Security researchers, red teamers, and AI engineers building LLM-powered security workflows who want to orchestrate Kali Linux tools through the Model Context Protocol — with validation, sandboxing, and shared memory between agents.
