Kali MCP

A warm, expressive MCP server that puts 56 Kali Linux pentesting tools at your AI agent's fingertips.

Kali MCP is a production-grade Model Context Protocol (MCP) server that exposes Kali Linux penetration-testing tools — nmap, sqlmap, nuclei, hydra, metasploit, ffuf, katana, subfinder, amass, bettercap, responder, zap, wpscan, and 44 more — to AI agents. Every tool call is validated against a JSON schema, every execution is sandboxed with timeouts, and every result is stored in a shared inter-agent vault.

Install from PyPI as kmcp (the repo is kali-mcp):

pip install kmcp
kmcp init  →  generate .env with a secure MCP_API_TOKEN
kmcp start  →  server on http://0.0.0.0:8399
kmcp studio  →  open the Playbook Studio UI
GitHub PyPI — kmcp
⚠️ Security warning: This server executes real offensive security tooling. Expose it only on a trusted local network — never on the public internet or in untrusted environments. Always set MCP_API_TOKEN when exposing beyond localhost, and ensure you have explicit authorization for every target you scan.

Key Features

  • 56 native Kali tool wrappers — nmap, sqlmap, nuclei, hydra, metasploit, ffuf, katana, subfinder, amass, bettercap, responder, zap, wpscan, and more
  • generic_command — escape hatch to run any shell command or pipeline not covered by a native wrapper
  • python_command — execute Python scripts directly on the host
  • Playbooks — multi-step pipelines (recon, webapp, AD, custom) with {{target}} substitution and resume support
  • parallel_execute — fan out to multiple tools concurrently, then aggregate and deduplicate results
  • Playbook Studio — built-in operator web UI at /studio for authoring, validating, publishing, and running multi-step playbooks
  • Inter-agent vault — SQLite-backed knowledge store; any agent can write findings, credentials, or notes and query them back
  • Live monitor TUI — kmcp monitor shows connected users, running jobs, and server health with SSE push
  • Safety — 3-layer timeout defense, process-tree cleanup, semaphore limits, output truncation, token-auth required

Quickstart

  1. pip install kmcp
  2. kmcp init — generates .env with a secure MCP_API_TOKEN
  3. kmcp start — boots the MCP server on :8399 (HTTP/SSE at /sse or streamable-http at /mcp)
  4. kmcp studio — opens the Playbook Studio UI in your browser

Who Is This For?

Security researchers, red teamers, and AI engineers building LLM-powered security workflows who want to orchestrate Kali Linux tools through the Model Context Protocol — with validation, sandboxing, required token auth, and shared memory between agents.
